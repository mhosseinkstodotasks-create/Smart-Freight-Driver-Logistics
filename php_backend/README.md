# مستندات فنی و راهنمای راه‌اندازی بک‌اند PHP و پایگاه داده MySQL

این بسته شامل معماری کامل بک‌اند PHP برای شرکت حمل‌ونقل و ترابری، مجهز به لایه آداپتور پایگاه داده (Database Adapter / Repository Layer) و اتصال به هوش مصنوعی است.

## ۱. ساختار پوشه‌ها و فایل‌ها

```
php_backend/
├── config/
│   ├── database.php          # اتصال PDO با UTF-8mb4 و Prepared Statements
│   ├── tables.php            # لایه نگاشت مرکزی جداول و ستون‌های واقعی MySQL
│   └── ai.php                # تنظیمات OpenAI ChatGPT / Gemini
├── repositories/
│   ├── BaseRepository.php    # کدهای پایه نگاشت پویای جداول و فیلدها
│   ├── DriverRepository.php  # عملیات و جستجوی رانندگان و تشخیص تکراری
│   ├── FleetRepository.php   # عملیات و جستجوی ناوگان/پلاک و کارت هوشمند
│   ├── FreightRepository.php # عملیات و جستجوی اعلام بارها
│   ├── TripRepository.php    # عملیات، ثبت و کوئری سفرهای مرتبط
│   └── ChatHistoryRepository.php # لاگ چت و تاریخچه استخراج هوش مصنوعی
├── services/
│   ├── ValidationService.php # اعتبارسنجی کدملی، نرمال‌سازی شماره همراه و پلاک
│   ├── AIExtractionService.php # استخراج داده ساختاریافته از پیام تلگرام/واتساپ
│   ├── DriverMatchingService.php # تطبیق و تشخیص هوشمند موارد تکراری
│   └── TripService.php       # ترکنش اتمیک تایید نهایی و ثبت سفر
├── api/
│   ├── extract.php           # اندپوینت استخراج هوش مصنوعی و بررسی تکراری
│   ├── confirm.php           # اندپوینت تایید نهایی و درج در دیتابیس
│   ├── trips.php             # اندپوینت لیست و جستجوی سفرها
│   ├── drivers.php           # اندپوینت لیست و جستجوی رانندگان
│   ├── fleets.php            # اندپوینت لیست و جستجوی ناوگان
│   └── freights.php          # اندپوینت لیست و جستجوی اعلام بارها
├── database_inspect.sql      # کوئری‌های کشف و بازرسی ساختار دیتابیس موجود
├── inspect_schema.php        # اسکریپت CLI بازرسی خودکار دیتابیس
└── schema_migration.sql      # اسکریپت ساخت دیتابیس و داده‌های نمونه اولیه
```

## ۲. نحوه تغییر نگاشت جداول و ستون‌ها در صورت تفاوت نام‌ها

اگر دیتابیس فعلی شرکت شما نام‌های دیگری دارد (مثلاً به جای `drivers` از `tbl_ranandegan` یا به جای `national_id` از `code_meli` استفاده می‌کند)، **نیازی به تغییر هیچ کوئری SQL در برنامه نیست!**

تنها فایل `config/tables.php` را باز کرده و نام جدول یا ستون مربوطه را تغییر دهید:

```php
'tables' => [
    'drivers' => 'tbl_ranandegan', // نام واقعی جدول شما
    'fleets'  => 'tbl_navgan',
    'freights'=> 'tbl_elam_bar',
    'trips'   => 'tbl_safaha',
],
'columns' => [
    'drivers' => [
        'national_id'   => 'code_meli',     // نام واقعی ستون کدملی
        'mobile_number' => 'shomare_hamrah',// نام واقعی ستون موبایل
    ]
]
```

## ۳. نحوه کشف خودکار ساختار دیتابیس با اسکریپت بازرسی

برای اینکه نام دقیق جداول و ستون‌های دیتابیس فعلی خود را ببینید، یکی از دو روش زیر را انجام دهید:

### روش اول: اجرای اسکریپت PHP در سرور
```bash
php inspect_schema.php
```
این اسکریپت ساختار تمام جداول و کلیدها را چاپ کرده و کد آماده کپی در `config/tables.php` را تولید می‌کند.

### روش دوم: اجرای اسکریپت SQL در phpMyAdmin یا دیتابیس
محتوای فایل `database_inspect.sql` را در تب SQL برنامه phpMyAdmin یا MySQL Workbench اجرا کنید.

## ۴. چرخه کاری ثبت بار و راننده (Workflow)

۱. کارمند پیام چت را در برنامه موبایل می‌فرستد (مثلاً متن تلگرام یا ایتا).
۲. برنامه پیام را به `POST /api/extract.php` ارسال می‌کند.
۳. هوش مصنوعی بدون دسترسی مستقیم به دیتابیس، ساختار JSON معتبر استخراج می‌کند.
۴. سیستم بک‌اند PHP با بررسی کدملی، شماره همراه، پلاک و شماره اعلام بار، موارد تکراری را شناسایی می‌کند.
۵. کارت پیش‌نمایش در چت با دو دکمه [تأیید و ثبت] و [ویرایش] نمایش داده می‌شود.
۶. پس از زدن تایید، اطلاعات به `POST /api/confirm.php` رفته و در تراکنش اتمیک MySQL ثبت می‌شود (از رکوردهای تکراری مجدداً استفاده شده و سفر جدید ایجاد می‌گردد).
